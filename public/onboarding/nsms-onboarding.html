Tambah Proyek03 / 05

Input Lead Baru

Isi form dengan data proyek: nama paket, instansi, nilai anggaran, dan status awal. Pastikan semua field wajib (*) terisi.

  • Funnel ID dibuat otomatis (mis. BST-0024) — tidak perlu diketik.
  • Nilai anggaran format rupiah, akan diformat otomatis saat disimpan.
  • Status awal biasanya 5% (Info Awal) atau 10% (Info Kebutuhan).

Rutinitas Mingguan04 / 05

Update Mingguan

Setiap minggu, pilih lead dari daftar kiri, pilih status terbaru, isi catatan perkembangan, lalu klik Simpan Update. Week label (mis. W17-2026) terisi otomatis.

  • Ingat: status hanya bisa naik atau tetap. Naik dari 50% ke 75%, bukan turun.
  • Catatan = info konkret (siapa ditemui, hasil presentasi, ekspektasi PO).

Aturan Penting05 / 05

Lead Terkunci 🔒

Lead dengan status Closing (100%) atau Gagal (0%) tidak bisa diedit lagi — dianggap final. Hubungi admin jika perlu membuka kembali.

  • Closing = PO sudah masuk → langsung jadi target tercapai.
  • Gagal = batal/kalah tender → tidak masuk forecast netto.
